# Remaining image and filesystem coverage

These are independently closable testability/policy gaps. Do not interpret every missing case as
a demonstrated defect. Discovery already canonicalizes configured roots and does not follow
symlink entries; thumbnails are lazy with four preparations in flight, not eager full-corpus work.

## ASSET-C01 — P2 · Gap · Basename filtering masks hash-reference assertions

**Evidence:** `tests/images.rs:124–159` uses candidates whose names are already referenced.
`src/images.rs:142–153` can reject by basename before exercising hash-key handling. Renamed duplicate
and changed-basename tests exist (`tests/images.rs:94–120,162–211`), but the key matrix is masked.

**Regression / close when:** Independently parameterize both legacy hash keys across both file lists
(publication and preview references), case-normalized digests included. Give every candidate a
*different basename* from its reference so only the hash can reject it. Also test byte-identical
unpublished files and overlapping roots; explicitly choose content-dedup versus path-count semantics.
Do not use all-zero placeholder hashes for this proof.

## ASSET-C02 — P2 · Gap · Root and access checks need adversarial filesystem fixtures

**Evidence:** `src/images.rs:90–129,175–195` handles configured roots/static escapes;
`tests/images.rs:15–69` covers selections and missing roots. Existing tests do not establish every
symlink, overlap or unreadable-directory case.

**Regression / close when:** Exercise nested/overlapping roots, in-root/out-of-root and dangling
symlinks, loops, relative data paths from another CWD, spaces/Unicode and unreadable files/dirs.
Run permissions cases unprivileged; root can bypass chmod. Preserve non-following traversal and
configured-root authorization. Final unlink substitution is separately owned by ASSET-01.
Use only temporary directories; never probe the real data tree.

## ASSET-C03 — P2 · Gap · Cache corruption, path types and simultaneous creators

**Evidence:** `src/images.rs:242–257` trusts existing entries; `tests/images.rs:215–351` proves
normal naming/reuse, MIME and real resize, not corrupt bytes or unexpected cache-path types.

**Regression / close when:** Exercise a corrupt entry, directory at expected filename, symlinked
entry and simultaneous creators under isolated cache roots. Assert a defined safe recovery/error
policy, correct decoded identity/dimensions and no partial entry treated as valid. Coordinate with
ASSET-04's B-under-A test. Keep valid lazy reuse and deterministic gates; no global cache reset.

## ASSET-C04 — P2 · Risk / decision · Conversion fallback can cache full-size originals

**Evidence:** `src/images.rs:270–276` deliberately falls back to copying the original when thumbnail
conversion fails. That permanent cache entry no longer has the usual resized-dimensions guarantee.
No measured resource incident was observed.

**Regression / close when:** In a child-only environment fail magick while retaining real identify;
prepare a bounded larger source and inspect actual cached dimensions/bytes and subsequent reuse.
Document the accepted fallback/resource ceiling and assert it, or retain a bounded failure instead.
Do not call a copied full-resolution original a successfully resized thumbnail.

## ASSET-C05 — P2 · Gap · Media admission and conversion fidelity need an explicit matrix

**Evidence:** `tests/images.rs:306–359` covers honest-suffix WebP and single-frame MIME examples;
its rejected MP4 is arbitrary bytes, not a decodable video. Discovery omits `.tif` while admitting
other documented formats. Existing publishing staging gives each record its own directory
(`src/publishing.rs:425–450`), so normal batches do not share one `upload.png` path.

**Regression / close when:** Cover transparent PNG/WebP, BMP/TIFF and the intended `.tif` policy;
use a genuinely decodable unsupported-media fixture where testing format rather than corruption.
Check output dimensions, representative pixels and alpha, plus repeated preparation in one attempt
directory and independent per-record staging. Preserve no-WebP upload behavior (ASSET-02) and the
sequence policy established by ASSET-05. Avoid adding large binary assets to Git.

## ASSET-C06 — P3 · Gap · Fixture names and sentinel bytes must not overstate proof

**Evidence:** `tests/common/mod.rs:57–71` creates real images and
`tests/images.rs:215–264` verifies 900×600 → 300×200. In contrast,
`tests/prompt_search.rs:49–50` and `src/workflow.rs:555–559` intentionally write arbitrary PNG-named
bytes for hash/lock tests; the common row also uses a placeholder hash.

**Close when:** Keep cheap byte fixtures for pure hashing/search/locking but label their scope.
Every codec, displayed-image, identity or actual provider/upload check uses decodable content and
computed hashes. Expected digests derive from generated bytes rather than encoder-version-specific
constants. The [fixture matrix](fixtures.md) captures missing combinations, not a demand to replace
all focused unit fixtures with expensive image generation.
